# АИС «Умный кампус»: Настройка репозитория и прав доступа

Данный репозиторий содержит исходный код и документацию проекта автоматизированной информационной системы «Умный кампус». В рамках Практической Работы №9 были настроены процессы обеспечения чистоты репозитория, кроссплатформенной совместимости и защиты веток.

## ⚙️ Конфигурация репозитория

### 1. Исключение артефактов (`.gitignore`)
Для предотвращения попадания в репозиторий мусорных файлов настроен `.gitignore`. В игнорируемые категории входят:
*   Результаты компиляции .NET: `bin/`, `obj/`.
*   Пользовательские настройки IDE Visual Studio: `.vs/`, `*.user`.
*   Локальные базы данных и хранилища: `*.mdf`, `*.sqlite`, `*.db`.
*   Временные файлы документов (Word/Excel): `~$*`.

### 2. Кроссплатформенная совместимость (`.gitattributes`)
В проекте могут работать разработчики на Windows, Linux и macOS. Для избежания конфликтов переводов строк (`CRLF` vs `LF`) в файл `.gitattributes` добавлено правило `* text=auto`. Также явно заданы форматы для исходного кода C# (`diff=csharp`) и бинарных файлов.

### 3. Git LFS (Large File Storage)
Для хранения тяжелых файлов (презентации, скриншоты, документация) подключен Git LFS. Это предотвращает раздувание основного репозитория.
*   **Отслеживаемые форматы:** `*.png`, `*.jpg`, `*.docx`, `*.pdf`.
*   **Внимание при клонировании:** Для корректного скачивания тяжелых файлов на локальную машину, на которой не установлен Git LFS, необходимо предварительно выполнить команду `git lfs install`.

## 🛡️ Правила защиты веток и Code Review

Ветка `main` является стабильной и защищена от прямых изменений (Branch Protection Rules). Любые доработки проходят через процесс Pull Request (PR).

**Правила для `main`:**
1.  Прямой `git push` в `main` запрещен.
2.  Для слияния изменений обязателен Pull Request.
3.  PR требует как минимум одного одобрения (Approve) от ревьюера (Require approvals: 1).
4.  Слияние разрешено только после успешного прохождения автоматических статус-чеков CI (сборка и тесты).

## 🚀 Быстрый старт

1. Установите Git LFS (если не установлен): `git lfs install`
2. Клонируйте репозиторий: `git clone <URL_репозитория>`
3. Откройте решение `CampusAIS.sln` в Visual Studio.
4. Для запуска шлюза выберите проект `CampusAIS.Gateway.Api` как Startup Project и нажмите F5.
